# Minecraft存档

Minecraft的存档是游戏世界的持久化文件，你可以手动导入，导出和分享给别人

## 手机版（ Android ）FCL

### 准备工作

- 长按下载QQ群里面的文件（自己存档也可，这里用QQ群下载的十五中存档举例）

<img width="250" src="/LumenGuide/img/ch10/10.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本">

- 下载MT管理器（当然你可以利用系统文件管理移动文件，那也可以完成；这里使用MT管理器教学）
> 官方渠道：[MT管理器](https://mt2.cn/ "Android上好用的文件管理器")

- 一些基础文件**存储位置**
> 一般情况下QQ下载文件位置在``` Android/data/com.tencent.mobileqq/Tencent/QQfile_recv ```
>
> FCL存档位置在``` /storage/emulated/你的安卓版本/FCL/.minecraft/versions/你的游戏版本/saves ```

- **MT管理器使用方法**摘要：

> **使用MT管理器进行解压**：如图长按压缩包，选择解压到 ; 选择解压到当前目录 
>
> <img width="250" src="/LumenGuide/img/ch10/12.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本"><img width="250" src="/LumenGuide/img/ch10/13.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本">

> **使用MT管理器移动文件**：MT管理器界面中有两个窗口，左侧通常显示本地文件 ；右侧则展示远程服务器文件（没有连接服务器时还是本地文件）。**MT 没有粘贴文件这个功能**，当你进行复制、移动、解压等操作时，是一步完成的。例如当你复制左边窗口的文件时，那么它将会被直接复制到右边窗口中。
>
> 你需要提前在**左侧窗口打开QQ下载的文件夹**，**右侧打开FCL放存档的文件夹**，然后如图长按文件，选择移动（顾名思义直接移动）或复制（保留左侧原文件，复制一份到右侧文件夹）
>
> <img width="250" src="/LumenGuide/img/ch10/14.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本"><img width="250" src="/LumenGuide/img/ch10/15.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本">

### 存档和服务器的使用

- 游戏启动后会进入<img src="/LumenGuide/img/ch10/7.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本">

- 存档导入

> 1. **解压存档**：一般情况下，你获得到的存档是一个压缩文件，你需要如下图
> 
> <img width="250" src="/LumenGuide/img/ch10/11.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本">
> 
> 你可以通过上面教程的 [「使用MT管理器进行解压」](使用MT管理器进行解压)进行解压
> 
> 2. **移动文件**：移动存档到存档文件夹，可以参考的FCL存档位置
> 
> 你可以通过上面教程的 [「使用MT管理器移动文件」](使用MT管理器移动文件)进行移动存档

> QQ下载文件位置在``` Android/data/com.tencent.mobileqq/Tencent/QQfile_recv ```
>
> FCL存档位置在``` /storage/emulated/你的安卓版本/FCL/.minecraft/versions/你的游戏版本/saves ```
> 
> 3. 现在可以启动游戏，点击单人游戏开始使用你的存档

- 服务器账号的登陆和注册

> 点击**多人游戏**进入<img src="/LumenGuide/img/ch10/16.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本">
> **点击 input** 打开键盘，输入服务器地址后按回车（完成）<img src="/LumenGuide/img/ch10/17.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本">
> *给服务器一个名字*（可选）点击完成<img src="/LumenGuide/img/ch10/18.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本">
> 点击进入<img src="/LumenGuide/img/ch10/19.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本">
> 进入服务器后，点击 “ T ” 按钮打开聊天框（命令框）<img src="/LumenGuide/img/ch10/20.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本">
> 首次登入，输入 ``` /register 你的密码 在输入一遍你的密码 ``` <img src="/LumenGuide/img/ch10/21.png" onerror="this.onerror=null;this.src='https://free.boltp.com'" alt="选择游戏版本">
> 在输入 ``` /login 你的密码 ``` ( login可以简化为l )
